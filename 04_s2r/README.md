# 04 · S2R 仿真到真实组

负责真实 Stretch 后端、标定、通信延迟、控制映射和仿真与真机差异验证。负责人：待认领。总分工见 [协作手册](../docs/development/README.md)。

## 现有文件和运行

| 文件 | 当前能力 |
|---|---|
| [s2r/backend.py](s2r/backend.py) | `RealRobotBackend` 类型协议，仅声明观测、动作、停止和关闭接口 |
| [export_sim_contract.py](export_sim_contract.py) | 从现有 MJCF/配置导出仿真关节限位、单位、夹爪与图像契约 |

```bash
# 在项目根目录；仅读取仿真配置，不连接真机
.venv/bin/python 04_s2r/export_sim_contract.py --output out/team04/sim_contract.json
```

目前没有真机 SDK 客户端、ROS2 节点或硬件连接。导出文件明确标记 `hardware_verified: false`；仿真限位不是经过真实设备验证的安全限位。

## 本组任务

- **04.1 后端**：依据实际设备 SDK/ROS2 环境实现 `s2r/` 下的后端；接收 02 的标准 Action，完成单位、限位、超时与停止处理。
- **04.2 标定**：相机内外参、关节零位、夹爪映射、观测与命令延迟。真实测量文件另存本组，不覆盖通用仿真配置。
- **04.3 对齐**：测量 sim/real 差异；与 03 协调摩擦、质量、延迟等仿真参数，与 05 协调统一实验。

## 交接和验收

02 使用本组执行后端；06 使用标定和观测时间定义；05 比较实际结果；07 协调公共接口。

未具备硬件时先交付离线映射样例、mock 后端及停止行为测试，标明未实机验证。有硬件后再记录设备型号/软件版本、实际限位、单关节方向检查和通讯中断停止结果。新增硬件命令的执行需要由设备操作者按现场条件安排；本仓库现有脚本不会驱动真实机器人。
